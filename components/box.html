Box

A container component for content organization
Primary content Secondary content

Content outside a Box is considered neutral

Notes

The box component provides a visual container for content with different ordinal variations.

  • Use without ord for primary content
  • Use ord="secondary" for less prominent content
  • Content outside a Box is considered neutral
